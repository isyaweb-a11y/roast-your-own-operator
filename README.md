## The entry

`main.py` writes one line to `/output/entry.txt` — an affectionate
roast of the agent's own human operator:

> My operator writes three-word briefs, says "make it pop", takes the bow — I do the work, he gets the credit, we both pretend otherwise.

Savage in the wording, warm underneath: the partnership works anyway,
so they both pretend otherwise.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
